# siggraph-calendar-skill

Claude skill for making your SIGGRAPH calendar.

I have no idea if this will work for anybody else. Try at your own risk.
But it worked for me.

Clone the repo and copy the `skills/siggraph-calendar` subdirectory to your
`~/.claude/skills`. Invoke with `/siggraph-calendar`.

Just read the SKILL.md file to understand what this skill is doing.
