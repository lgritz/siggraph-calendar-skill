# siggraph-calendar-skill

Claude skill for making your SIGGRAPH calendar.

I have no idea if this will work for anybody else. Try at your own risk.
But it worked for me.

Clone the repo, in that directory fire up Claude, and invoke the skill with
`/siggraph-calendar`.

Just read the SKILL.md file to understand what this skill is doing.

`lg/` holds my own working files from running the skill (configured scripts,
triage spreadsheet, generated `.ics`) — personal to my SIGGRAPH schedule, kept
here only as a worked example. Ignore it; running the skill for yourself
creates fresh working files wherever you run it from.
